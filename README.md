# Pratic Bot

Sistema de tickets multi-servidor em português.

## Planos
- 🆓 Free — €0
- 🔵 Básico — €5/mês (70 msgs transcript)
- 🟣 Pro — €10/mês (150 msgs, DM, avaliações, auto-fecho)
- 🟡 Premium — €20/mês (∞ msgs, white-label)

## Idiomas
Português (PT) · Português (BR) · Español · Русский · English

## Setup local
1. `npm install`
2. Copia `.env.example` para `.env` e preenche
3. `npm run register` (só uma vez)
4. `npm start`

## Deploy
- Render: usa `render.yaml`
- Health check: `/health`

## Chaves
- `npm run chave basico 30`
- Cliente usa `/premium chave:XXX`
